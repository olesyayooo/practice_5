# Принципиальные решения

1. Проверка и расчёт разделены. TimesheetAnalyzer возвращает массив только после проверки всех пяти полей; любая ошибка прекращает обработку и сообщает позицию. split(";", -1) сохраняет пустые поля в конце строки.

2. Все параметры сосредоточены в TimesheetAnalyzer. Для варианта 6 WEEKLY_NORM равна 35, а дневной порог остаётся 8. Это позволяет менять норму без изменения алгоритма расчёта.
